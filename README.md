### Projetos

**[Campaign Engagement Console](https://github.com/driihcoutinho/salesforce-campaign-engagement-console)** — Salesforce · LWC + Apex

Componente Lightning que pontua membros de campanha por engajamento e registra interações em lote. Segurança delegada à plataforma com `WITH USER_MODE`, operação atômica via savepoint e bulkificação real — 1 SOQL e 3 DML independentemente do volume. **17 testes Apex, 90,8% de cobertura**, validados contra org real. Usa só objetos padrão, então faz deploy em qualquer org.

**[SFMC CloudPages Toolkit](https://github.com/driihcoutinho/sfmc-cloudpages-toolkit)** — Marketing Cloud · Ampscript + SSJS

Captura de lead com honeypot e upsert idempotente, relatório de campanhas renderizado no servidor com escape de HTML, e sincronização de Data Extension pela REST API com OAuth 2.0, envio em lote e teto de retentativas. Credenciais fora do código, em Data Extension restrita.

**[AeroQuiz](https://github.com/driihcoutinho/aeroquiz)** — React + TypeScript · Express · PWA

Comecei para minha esposa estudar no processo seletivo da LATAM; outros comissários passaram a usar, e virou case no LinkedIn. As 1.270 questões oficiais do CMS ANAC não foram digitadas: um pipeline em TypeScript lê os DOCX oficiais, separa enunciado e alternativas, cruza com os gabaritos e descarta o que não bate. Schema Zod compartilhado entre cliente e servidor, progresso salvo localmente e funcionamento offline.
